## 🚀 Live Preview & Quick Start

## 🎨 Features & Highlights

- **✨ Modern UI & UX Design**:
  - Dark mode by default with seamless **Dark / Light theme switch** (saves preference in `localStorage`).
  - Press <kbd>T</kbd> anywhere on the page to instantly toggle the theme.
  - Interactive glowing particles canvas background.
  - Custom fluid glowing cursor follower (automatically disabled on touch devices).
  - 3D interactive tilt effect on the hero code card.
  - Smooth typing headline animation.

- **🎓 Academic Spotlight**:
  - Dedicated showcase for **Swami Rama Himalayan University (SRHU)** and **School of Science & Technology**.
  - Coursework highlights: Data Structures & Algorithms, Object-Oriented Programming (C++/Java), Web Technologies, Database Systems, Computer Networks, and Software Engineering.

- **🛠️ Interactive Technical Skills**:
  - Filter skills by categories: *Frontend & Web*, *Programming Languages*, *Databases & Tools*, *Core & Professional*.
  - Visual animated progress indicators.

- **💻 Featured Project Showcase**:
  - Filterable by project category (*Web Applications*, *JavaScript*, *Academic & Utility*).
  - Interactive project detail modal with overview, key features, and tech stacks.
  - 6 featured projects tailored for a standout BCA portfolio:
    1. **CampusConnect** - SRHU BCA Student Hub & Notes Repository
    2. **WeatherPulse** - Dynamic Meteorological Weather Forecast
    3. **EduTrack** - Collegiate GPA & Attendance Planner
    4. **TaskMaster** - Kanban Drag-and-Drop Productivity Board
    5. **BCA TechQuiz** - Computer Science Challenge Arena

- **⚡ Interactive Developer Terminal**:
  - Built-in terminal emulator with interactive commands:
    `help`, `about`, `srhu`, `skills`, `projects`, `contact`, `resume`, `theme`, `date`, `clear`.
  - Quick clickable command chips for mobile and fast exploration.

- **📄 Printable Resume Modal**:
  - Clean A4 formatted resume preview right in the browser.

- **📬 Functional Contact Form & Quick Actions**:
  - Client-side validation for Name, Email, Subject, and Message.

## 🛠️ How to Customize

1. **Update Personal Links & Email**:
   - In `index.html`, search for `manishanegi.dev@gmail.com` and replace it with your actual personal email address.
   - Update your GitHub and LinkedIn profile links in the hero and contact sections.
2. **Add / Replace Projects**:
   - In `index.html` and `js/script.js` (`projectData` object), you can update the titles, descriptions, and repository links as you build new projects.
3. **Deploying for Free**:
   - **GitHub Pages**: Push this repository to GitHub, go to `Settings > Pages`, and select the `main` branch to get a free live URL (e.g., `https://manishanegi.github.io/portfolio`).
   - **Vercel / Netlify**: Drag and drop the folder directly onto [Netlify Drop](https://app.netlify.com/drop) or connect to Vercel for instant deployment.
